# 🚀 V-Bridge AI Lab

> Connecting Indian MSMEs & Startups to Global Opportunities through Artificial Intelligence.

---

## Overview

V-Bridge AI Lab is an AI-powered business intelligence platform that helps MSMEs, Startups, Investors, Buyers, Suppliers, and Partners discover meaningful business opportunities.

Unlike traditional B2B directories, V-Bridge uses AI to understand business profiles, generate intelligent recommendations, and identify high-value partnerships.

# Development

Clone repository

```bash
git clone https://github.com/<username>/vbridge-ai-lab.git
```

Install frontend

```bash
npm install
```

Run frontend

```bash
npm run dev
```

Backend

```bash
python -m venv venv

source venv/bin/activate

pip install -r requirements.txt
```

Run API

```bash
uvicorn app.main:app --reload
```
